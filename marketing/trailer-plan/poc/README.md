# Proof-of-concept source

Remotion compositions used for the proof-of-concept renders in `../evidence/poc/`.

- `src/Interaction.jsx`: the animated product interaction (Mia claims Priya's question and replies). Every UI pixel comes from lossless 3x captures of the running Spine 2.0 app; the only drawn elements are the cursor and the caption.
- `src/Poc.jsx`: plate + corner-pinned UI + the screen-dive transition into the interaction.
- `src/geom.js`: homography (4-point) and CSS `matrix3d`.
- `find_screen.py`: finds the flat grey screen in a plate and returns its corners (sub-pixel).
- `render.mjs`: `node render.mjs <CompositionId> <out.mp4>` (expects `public/ui/*.png`, `public/grain/*.png`, and the plate).

The UI captures and grain frames are not committed (large binaries); they are regenerated by the capture step described in PRODUCTION-PLAN.md.
